# 🎮 Tic-Tac-Toe Game

A simple **Tic-Tac-Toe game developed using Java**. This project demonstrates basic Java programming concepts, object-oriented programming, GUI development, and event handling.

## 📌 Project Overview

This application allows two players to play the classic Tic-Tac-Toe game on a graphical user interface.

Players take turns placing **X** and **O** on a 3×3 game board. The application checks the board after each move to determine whether a player has won or whether the game ends in a draw.

## ✨ Features

* 🎮 Two-player gameplay
* 🧩 Interactive 3×3 game board
* ❌ X and O player turns
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔄 Game restart functionality
* 🖥️ Graphical User Interface (GUI)
* 🖱️ Button-based player interaction

## 🎯 How to Play

1. Start the application.
2. Player 1 starts with **X**.
3. Player 2 plays with **O**.
4. Players take turns selecting an empty position.
5. The first player to get three matching symbols horizontally, vertically, or diagonally wins.
6. If all positions are filled without a winner, the game ends in a draw.
7. Restart the game to play again.

## ▶️ How to Run

### Using a Java IDE

1. Clone or download this repository.
2. Open the project in a Java IDE such as **NetBeans** or **IntelliJ IDEA**.
3. Open `TicTacToe.java` or `App.java`.
4. Build the project.
5. Run the application.

### Using Command Line

Compile the Java source files:

```bash
javac TicTacToe.java
```

Run the application:

```bash
java TicTacToe
```
